A clean personal portfolio website showcasing development and design services.

## 📝 Overview

**ServicesRam** is a static portfolio website built using fundamental web technologies. It presents project offerings, contact information, and personal branding in a minimal, professional layout.

---

## 🛠️ Tech Stack

- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript (Vanilla)** – Dynamic behavior
- **Vercel** – Hosting & Deployment
